## 旧账号归属

服务器实际配置显示，校园版和企业版共用 `xicaitansuo` 数据库，原有 16 个账号；金融版使用独立 `cst_finance` 数据库，原有 2 个账号。

经用户明确选择：共享库的全部旧账号归校园版，企业版用户重新注册。金融版原有账号归金融版。原用户 ID、密码哈希、邮箱、手机号、创建时间、已有积分余额和微信绑定均已逐条核对保留。

企业版另外初始化了独立管理员 `admin`，未复制校园版管理员的密码或业务记录。密码在服务器本地随机生成，存放于 root 可读的：

```text
/etc/cst-account-editions/b2f0342-20261103/enterprise.env
```

服务器授权管理员可查看新密码：

```sh
sudo sed -n 's/^ENTERPRISE_ADMIN_PASSWORD=//p' /etc/cst-account-editions/b2f0342-20261103/enterprise.env
```

修改此初始化配置不会修改已创建账号的密码。校园版原管理员密码、金融版原管理员密码没有被重置。
