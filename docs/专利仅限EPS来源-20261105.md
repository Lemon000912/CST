# 专利仅限 EPS 来源

校园版、企业版、金融版统一执行：专利只展示 European Publication Server（EPS）可核验的欧洲 EP 文献，暂停 Google Patents、OpenAlex 专利、CNIPA、USPTO、Espacenet、J-PlatPat 等专利渠道。普通网页和论文检索继续保留。

输入明确 EP 公开号时直接访问 EPS 官方 XML；关键词检索优先复用英文改写，生成最多三组同义检索词，通过当前配置的联网索引定位 EPS 页面；同时使用最多两个 IPC 分类号查询 EPS 自身公开分类索引。只从 EPS XML 获取标题、正文并核对公开号和文献类型。改写模型只有推理没有英文结果时，使用独立 B 模型补一次英文关键词。候选原文最多核验 96 份，最多四个并发、整条专利链路 30 秒，原文缓存最多 256 项、一小时过期。检索按主题筛选并保留相关性分数到最终摘录排序，腐蚀测量问题不使用单纯电压测量或防腐材料凑数。未找到原文、请求失败或编号不一致时不展示该条目，也不回退到其他专利渠道。EPS 不覆盖全部国家的专利，关键词结果可能减少或为空，不猜测 CN、US、JP 等编号的 EP 同族。

回答保持原有正文和数字引用圆圈；专利引用链接为 EPS 官方 REST PDF 地址。模型 A、B 和仲裁都执行来源限制及本轮 EP 白名单。搜索缓存使用新策略版本，普通网页混入的其他专利页和旧专利条目会再次过滤。历史回答保留原内容，需要重新搜索才能使用新策略。旧的 `PATENT_PUBLIC_SOURCES` 环境配置暂不生效。

验证包括：EPS 两代 XML、编号不一致、HTML 空壳、官方域名校验、取消请求、普通网页混入专利、普通论文保留、三模型摘录及白名单检查，以及服务器真实 EP 原文请求。另使用中文地下电线腐蚀非接触测量问题验证完整检索和模型 C 仲裁，并用铝合金电缆与锂电池预警问题验证关键词召回。

部署前保存各版本原文件、权限、属主、文件摘要及 RELEASE.json，失败时自动恢复。手动回退入口：

```sh
sudo python3 /var/lib/cst-account-editions/eps-recall-20261105/rollback.py --check
sudo python3 /var/lib/cst-account-editions/eps-recall-20261105/rollback.py --apply
```

`--check` 核对当前补丁和备份摘要；`--apply` 恢复部署前文件并重启三个 API，检查各版本健康状态。此次补丁不修改数据库、账户、环境变量和前端文件，也保留此前的数据表生成修复。
