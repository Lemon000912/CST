# 校园版与企业版双域名部署

项目使用同一套源码生成两个独立程序：

- 校园版前端：`dist-school`，后端端口 `8787`，固定 `APP_EDITION=school`
- 企业版前端：`dist-enterprise`，后端端口 `8788`，固定 `APP_EDITION=enterprise`

两个后端共用 PostgreSQL、JWT 密钥和用户账号。聊天记录按版本分别保存。企业版搜索、图表和 PDF 操作不扣积分，校园版继续正常计费。

企业版服务首次启动时，如果数据库中不存在 `admin`，会自动创建默认管理员：用户名 `admin`，密码 `admin123`。已有同名账号不会被覆盖；生产环境首次登录后应立即修改密码，并可在 `ailunwen-enterprise.env` 中覆盖默认值。

## 本地开发

```bash
npm run dev:school
npm run dev:enterprise
```

也可以同时启动：

```bash
npm run dev:both
```

默认地址：

- 校园版前端 `http://127.0.0.1:5175`，API `http://127.0.0.1:8787`
- 企业版前端 `http://127.0.0.1:5176`，API `http://127.0.0.1:8788`

## 构建

```bash
npm run build:all
```

也可以单独构建：

```bash
npm run build:school
npm run build:enterprise
```

## 服务器安装

确认两个域名均已解析到同一台服务器，并在项目 `.env` 或服务器私密环境文件中配置相同的 `DATABASE_URL` 和 `JWT_SECRET`。

```bash
SCHOOL_DOMAIN=school.example.com \
ENTERPRISE_DOMAIN=enterprise.example.com \
npm run install:editions
```

安装脚本使用 Apache，生成两个虚拟主机，并安装：

- `ailunwen-school-api.service`
- `ailunwen-enterprise-api.service`
- `ailunwen-pdf-sync.service`（两个版本共用一个 PDF 同步任务）

代码更新后执行：

```bash
npm run update:editions
```

## 微信登录

两个域名需要不同的回调地址。公共密钥放在：

```text
/home/ubuntu/ailunwen-secrets/ailunwen.env
```

校园版专用配置放在 `ailunwen-school.env`：

```dotenv
WECHAT_OPEN_REDIRECT_URI=https://school.example.com/api/v1/auth/wechat/callback
WECHAT_OPEN_FRONTEND_URL=https://school.example.com/
```

企业版专用配置放在 `ailunwen-enterprise.env`：

```dotenv
WECHAT_OPEN_REDIRECT_URI=https://enterprise.example.com/api/v1/auth/wechat/callback
WECHAT_OPEN_FRONTEND_URL=https://enterprise.example.com/
```

两个域名都需要加入微信开放平台允许的授权回调域。生产环境应配置 HTTPS。
