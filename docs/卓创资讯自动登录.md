# 卓创资讯自动登录

`npm run sci99:login` 打开卓创资讯用户中心，切换“账号密码登录”，自动填写账号密码、勾选用户协议及隐私政策，然后提交登录。只有页面离开登录路由、显示与配置账号一致的“您好”按钮和用户中心“工作台”，才认定登录成功。

## 配置与运行

在项目根目录 `.env.local` 中配置（该文件已被 Git 忽略）：

```dotenv
SCI99_ACCOUNT=你的账号
SCI99_PASSWORD=你的密码
SCI99_BROWSER_CHANNEL=msedge
SCI99_LOGIN_TIMEOUT_MS=30000
```

```powershell
npm run sci99:login
```

Windows 默认使用已安装的 Microsoft Edge，其它系统默认使用 Playwright Chromium（需执行 `npx playwright install chromium`）。默认保留登录后的浏览器窗口，关闭窗口后脚本退出。`--close` 在运行结束后关闭窗口，`--headless` 隐藏窗口并自动关闭。自动登录超时或密码错误会报错，不反复提交密码，也不进入人工处理流程。

协议使用 Element UI 自定义复选框：原始输入框从无障碍树中隐藏，脚本通过组件选择器读取状态，点击可见图标后校验确已选中，兼容原先已勾选的状态。登录切换到账号密码模式，采用本次实测成功的登录流程。

账号密码从环境变量、`.env.local`、`.env` 依次读取，不写入源码和日志。浏览器会话不持久化到磁盘；需要后续采集时，复用同一 context：

```js
import { chromium } from "playwright";
import { loginSci99 } from "./backend/sci99Login.js";

const browser = await chromium.launch({ channel: "msedge", headless: false });
try {
  const context = await browser.newContext();
  const page = await context.newPage();
  await loginSci99(page, {
    account: process.env.SCI99_ACCOUNT,
    password: process.env.SCI99_PASSWORD,
    onStatus: console.log,
  });
  // 在同一 context 中继续访问卓创资讯。
} finally {
  await browser.close();
}
```

此功能是独立登录脚本和可复用函数，金融版现有公开网站检索尚未接入此浏览器会话。

`npm run test:sci99` 使用本地拦截页面测试自定义协议勾选、SPA 跳转、延迟登录、密码错误、超时、会话复用及账号身份校验，不访问真实账户。
