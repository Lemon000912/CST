# 东方财富自动登录

运行 `npm run eastmoney:login`，脚本会打开东方财富个人中心，切换账号登录、填写账号密码、勾选协议、点击登录，再点击“开始验证”。验证通过后继续提交，并通过个人中心“退出”入口确认登录成功。

## 使用

安装项目依赖后，在项目根目录的 `.env.local` 中填写：

```dotenv
EASTMONEY_ACCOUNT=你的手机号或邮箱
EASTMONEY_PASSWORD=你的密码
```

`.env.local` 已被 Git 忽略。脚本不会输出密码，也不会保存 Cookie、截图或浏览器配置。环境变量优先于 `.env.local`，后者优先于 `.env`。

```powershell
npm run eastmoney:login
```

Windows 默认使用已安装的 Microsoft Edge。其它系统或希望使用独立 Chromium 时：

```sh
npx playwright install chromium
```

并在 `.env.local` 添加 `EASTMONEY_BROWSER_CHANNEL=chromium`。

脚本会自动点击“开始验证”，验证通过后自动完成登录，和本次实测通过的点击验证流程一致。自动验证超时默认 30 秒，可通过 `EASTMONEY_VERIFY_TIMEOUT_MS` 调整。网站未自动通过验证时直接报错结束，不进入人工处理流程。图片、拼图、滑块和短信验证的自动识别不在本实现范围内。

脚本自动完成验证和登录，默认在成功或失败后保留浏览器窗口，方便继续使用或查看状态；关闭窗口后脚本退出，不要求按回车。添加 `--close` 可在运行结束后自动关闭，`--headless` 隐藏窗口并在结束后自动关闭。关闭后该次临时浏览器会话结束；需要登录后继续采集时，使用下面的函数，在同一 context 内执行后续操作。

验证码组件可能同时生成多个“验证成功”元素，脚本只读取可见匹配。出现“登录中”后等待网站完成跳转与单点登录，不将这个中间状态当作失败；必要时在独立页面检查会话，避免刷新原页面打断登录。

## 在其它代码中复用

```js
import { chromium } from "playwright";
import { loginEastmoney } from "./backend/eastmoneyLogin.js";

const browser = await chromium.launch({ channel: "msedge", headless: false });
try {
  const context = await browser.newContext();
  const page = await context.newPage();
  await loginEastmoney(page, {
    account: process.env.EASTMONEY_ACCOUNT,
    password: process.env.EASTMONEY_PASSWORD,
    onStatus: console.log,
  });
  // 在同一 context 中继续访问东方财富，才能使用本次登录会话。
  // 在这里执行需要登录的页面操作。
} finally {
  await browser.close();
}
```

此功能提供独立登录脚本和可复用函数。金融版现有的公开网站搜索与 HTTP 正文抓取尚未接入这个浏览器会话。

## 验证

`npm run test:eastmoney` 使用本地拦截页面验证跨域 iframe、协议勾选、网站自动提交、验证通过后由脚本自动提交、重复的验证成功元素、延迟单点登录、iframe 跳转销毁、密码错误、验证码超时及假成功状态；不访问真实账户。此测试需要上述 Edge 或 Chromium 浏览器。

实现采用 Playwright 的 [FrameLocator](https://playwright.dev/docs/api/class-framelocator) 操作嵌入式表单，并使用官方支持的 [Edge／Chromium 浏览器通道](https://playwright.dev/docs/browsers#google-chrome--microsoft-edge)。
