# 专利圆圈跳转

按用户最终要求恢复最初的回答样式：移除“专利原文与官方入口”区域、编号自动链接和额外的 PDF/检索文字，保留正文和原有数字圆圈。只修改能明确识别的欧洲 EP 引用地址，使圆圈打开 European Publication Server 的对应 PDF；A2、A3、B1 等版本分别处理。

原来源已明确指向 EP 文献时，使用该编号。一个段落中只有一个明确 EP 公开号时，可以使用该段落公开号定位对应圆圈；同段涉及多个专利且来源不能消歧时保留原地址。不会根据 JP、US、CN 编号猜测欧洲同族编号。代码、普通文字链接和没有引用的编号不做改写。

官方格式沿用已验证的 REST 1.2：

```text
https://data.epo.org/publication-server/rest/v1.2/patents/EP0816797NWB1/document.pdf
https://data.epo.org/publication-server/rest/v1.2/patents/EP0816797NWA2/document.pdf
```

本次只切换三版前端的 Apache DocumentRoot，不重启后端。首页保留 HTML 缓存重新验证配置，浏览器刷新后加载新版本。

## 恢复点

本次备份目录：`/var/lib/cst-account-editions/patent-circles-20261105/`。

检查恢复条件：

```sh
sudo python3 /var/lib/cst-account-editions/patent-circles-20261105/rollback.py --check
```

撤回本次改动（回到紧邻上一版的 EPO 入口卡片方案）：

```sh
sudo python3 /var/lib/cst-account-editions/patent-circles-20261105/rollback.py --apply
```

如果要撤回所有专利展示改动，恢复最初的样式和跳转地址，在上一步成功后依次恢复两个更早的独立恢复点：

```sh
sudo python3 /var/lib/cst-account-editions/patent-eps-20261105/rollback.py --check
sudo python3 /var/lib/cst-account-editions/patent-eps-20261105/rollback.py --apply
sudo python3 /var/lib/cst-account-editions/patent-links-20261105/rollback.py --check
sudo python3 /var/lib/cst-account-editions/patent-links-20261105/rollback.py --apply
```

这些操作只恢复前端与 Apache 配置；保留账号、对话、积分、后台程序和数据表生成修复。每个脚本会核对备份、当前配置及旧前端文件，拒绝覆盖其他运维已修改的配置。
