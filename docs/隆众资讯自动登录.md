# 隆众资讯自动登录

运行 `npm run oilchem:login`，脚本会打开隆众资讯登录页，切换“账号登录”，自动填写用户名和密码，勾选“我已阅读并接受隆众资讯《用户协议》和《隐私政策》”及“记住密码”，再点击登录。只有页面同时出现“会员中心”和“退出”入口，才认定登录成功。

## 配置与运行

在项目根目录 `.env.local` 中配置（该文件已被 Git 忽略）：

```dotenv
OILCHEM_ACCOUNT=你的用户名
OILCHEM_PASSWORD=你的密码
OILCHEM_BROWSER_CHANNEL=msedge
OILCHEM_LOGIN_TIMEOUT_MS=30000
```

```powershell
npm run oilchem:login
```

Windows 默认使用已安装的 Microsoft Edge。其它系统默认使用 Playwright Chromium；需先执行 `npx playwright install chromium`。也可用 `OILCHEM_BROWSER_CHANNEL` 指定浏览器通道。

默认在登录结束后保留浏览器，方便继续使用；关闭窗口后脚本退出。`--close` 会在运行结束后自动关闭，`--headless` 隐藏浏览器并自动关闭。登录流程无需人工操作；如果网站未确认登录成功，在限定时间内报错，不反复提交密码。

脚本会勾选网站的“记住密码”，当前实现使用独立的临时浏览器会话，不保存浏览器配置或 Cookie 到磁盘。账号密码从环境变量、`.env.local`、`.env` 依次读取，不写入源码或日志。

## 复用函数

```js
import { chromium } from "playwright";
import { loginOilchem } from "./backend/oilchemLogin.js";

const browser = await chromium.launch({ channel: "msedge", headless: false });
try {
  const context = await browser.newContext();
  const page = await context.newPage();
  await loginOilchem(page, {
    account: process.env.OILCHEM_ACCOUNT,
    password: process.env.OILCHEM_PASSWORD,
    onStatus: console.log,
  });
  // 在同一个 context 中继续访问隆众资讯，使用本次登录会话。
} finally {
  await browser.close();
}
```

这是独立登录脚本和可复用函数，金融版现有公开网站检索尚未使用此浏览器会话。

`npm run test:oilchem` 使用拦截页面验证双勾选、已勾选状态、登录跳转、错误密码、超时与会话复用，不访问真实账户。
