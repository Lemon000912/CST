# 专利链接展示变更与撤回

本次只修改前端 Markdown 展示，不修改检索、模型提示、数据库和账号体系。

## 展示效果

- 正文中的 CN、EP、US、WO 等专利公开号自动显示为可点击文字。
- 检索题录已经提供对应专利来源页时，点击编号打开该来源；存在独立 PDF 地址时，旁边显示“原文 PDF”。
- 没有对应题录来源的编号显示“（检索）”，打开按编号检索的入口，不生成未经核实的专利直达页或 PDF 地址。
- EPO、Espacenet、Google Patents 等已有专利链接保留原来的文字或网址，不再统一压缩为域名角标。数字引用仍保留角标样式。
- 已有链接、代码、表格和历史消息中的原始文字保持结构；新前端可以为历史消息补上可点击入口。

## 发布与备份

发布三个独立前端目录，通过 Apache DocumentRoot 切换；后端服务不需要重启。之前各站点的前端目录保留。

服务器专用记录目录：

```text
/var/lib/cst-account-editions/patent-links-20261105/
```

该目录保存发布前的 Apache 配置、文件属主权限、原前端目录及配置哈希，并提供独立的 `rollback.py`。撤回脚本不依赖本地电脑或 GitHub。

## 对效果不满意时撤回

先检查备份及当前配置是否仍与本次发布一致：

```sh
sudo python3 /var/lib/cst-account-editions/patent-links-20261105/rollback.py --check
```

确认要撤回后执行：

```sh
sudo python3 /var/lib/cst-account-editions/patent-links-20261105/rollback.py --apply
```

脚本恢复三个站点发布前的 Apache 配置，执行语法检查并 reload Apache。浏览器刷新后恢复旧版前端。账号、历史会话、积分及已部署的数据表修复不随此操作回退。

如果配置在发布后已被其他运维操作改动，脚本会拒绝覆盖，需先核对差异。源代码层面可单独 revert 本次“专利链接展示”的提交，再重新构建，不需要回退其他功能提交。

## 验证范围

包含 Markdown 结构转换、来源页/PDF 对应、未核实编号检索、链接安全、代码与既有链接保护的专项测试。通过模拟会话在实际 App 页面验证可点击文字、跳转地址与新标签打开；样例专利及 PDF 仅用于展示验证，不作为专利真实性证明。
