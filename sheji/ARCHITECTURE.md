## 🔄 核心业务流程

### 1. 用户查询流程

```
用户提问
    │
    ▼
┌─────────────────┐
│ 1. 用户登录/注册 │ ◄── SQL存储用户信息

    │
    ▼
┌─────────────────┐
│ 2. 读取用户记忆  │ ◄── Redis读取历史主题、偏好
└─────────────────┘
    │
    ▼
┌─────────────────────────┐
│ 3. 大模型理解并重写检索词 │ ◄── LLM Service
└─────────────────────────┘
    │
    ▼
┌─────────────────────────┐
│ 4. 用户选择检索方式      │
│    (网页/数据库/两者)    │
└─────────────────────────┘
    │
    ├──► 网页检索 ──► 补充网页数据
    │
    └──► 数据库检索 ──► SQL查询
    │
    ▼
┌─────────────────────────┐
│ 5. 数据融合 (CE+GStack)  │ ◄── Fusion Service
│    - 论文排序            │
```

## 🔧 技术组件说明

### 1. FastAPI 后端框架
- **特点**: 异步高性能、自动API文档、类型注解
- **用途**: RESTful API接口、WebSocket支持

### 2. PostgreSQL 数据库
- **特点**: ACID事务、JSON支持、全文检索
- **用途**: 用户数据、论文元数据、搜索历史

### 3. Redis 缓存
- **特点**: 内存存储、高性能、支持过期
- **用途**: 用户会话、搜索历史、热点数据

### 4. ChromaDB 向量数据库
- **特点**: 嵌入式、语义检索、相似度计算
- **用途**: 文档向量存储、语义搜索

### 5. LLM 服务集成
- **OpenAI GPT-4**: 通用语言理解和生成
- **Claude Sonnet**: 长文本处理和推理
- **DeepSeek**: 代码和科学文献理解

### 6. 数据融合算法 (CE + GStack)
- **Cross-Encoder**: 计算查询-文档相关性
- **GStack**: 基于图的结果排序和融合
- **功能**: 去重、排序、可信度评估

## 📈 性能优化策略

1. **缓存策略**
   - Redis缓存热点查询结果
   - 用户记忆本地缓存

2. **异步处理**
   - 文档解析异步执行
   - 大模型调用异步化

3. **数据库优化**
   - 全文检索索引
   - 查询结果分页

4. **向量检索**
   - 预计算文档向量
   - 近似最近邻搜索
