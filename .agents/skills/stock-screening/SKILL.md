# 选股工具

先把自然语言偏好转换为可衡量的指标，再执行或说明如何执行筛选。用户未给条件时，先询问市场、期限、风险偏好和关注方向；也可提供明确标为示例的默认框架。

## 工作步骤

1. 确认市场、行业限制、投资期限、风险容忍度及是否排除特定证券。
2. 将条件分为基本面、估值、质量、成长、股息和流动性指标，说明定义、阈值、数据时点与筛选理由。
3. 优先使用可核查的近期数据；明确复权、财年、币种等口径。若没有筛选数据源，不得伪造筛选结果，应给出查询步骤或表格模板。
4. 对候选结果做异常项检查，如一次性损益、负债、稀释、低流动性和行业周期性。
5. 对比候选公司的优势、短板和需要进一步研究的问题；说明筛选条件会遗漏什么。

## 输出格式

- 用户条件及采用的假设
- 筛选指标、口径和阈值
- 候选名单（含数据时点和来源）
- 候选对比与排除理由
- 局限、风险及后续核查事项

筛选仅用于研究起点，不把排名或入选表述为买入建议，也不承诺收益。
