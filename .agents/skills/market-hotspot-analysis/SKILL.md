# 市场热点分析

把“发生了什么”“为什么发生”和“可能意味着什么”分开回答。凡涉及当前市场或新闻，先核实最新资料并标注时间。

## 工作步骤

1. 明确市场范围（A 股、港股、美股等）、时间窗口和用户关心的行业/资产。
2. 汇总有代表性的价格、成交、资金或行业数据；注明交易日、口径与数据来源，不能核实时明确说明。
3. 根据公告、政策、财报和可信新闻识别事件催化，区分已确认事实、市场解释与未经证实的传闻。
4. 说明热点传导路径、受影响行业/公司及可能的反向影响；避免把相关性当作因果。
5. 给出持续性观察指标、可能失效条件和短期/中期风险，不根据单日涨跌推断长期趋势。

## 输出格式

- 市场与时间范围
- 热点及数据证据
- 驱动因素（事实/解释）
- 产业链影响与观察指标
- 风险、反例和后续核查
- 来源与更新时间

不把热点归纳包装成确定性预测或个性化交易建议。
