# 个股研究

围绕用户指定的公司形成可核查、平衡的研究摘要。先确认公司名称、股票代码、市场和分析时点；无法确认时先说明假设。

## 工作步骤

1. 确认分析范围与时点。涉及最新行情、公告或财报时，先检索可靠的一手来源；注明来源和发布日期，不把过期数据写成当前事实。
2. 概述公司主营业务、收入构成、产业链位置和主要市场，区分公司披露与外部估算。
3. 分析近年收入、利润、现金流、负债和资本回报的趋势；解释显著变化，避免只引用单一年度或单一指标。
4. 梳理竞争格局、可持续优势、增长驱动和关键依赖，并与主要可比公司作有边界的比较。
5. 列出估值所需的关键假设及敏感变量；数据不足时只给估值框架，不捏造目标价。
6. 汇总多头逻辑、反方观点、经营/财务/治理风险和需要继续验证的问题。

## 输出格式

- 结论摘要（带分析时点）
- 业务与竞争位置
- 财务表现和变化原因
- 估值线索与关键假设
- 催化因素、风险及待核查事项
- 来源清单

将事实、推断和假设分开标注；保持中性，不给出保证收益的承诺或个性化买卖指令。
